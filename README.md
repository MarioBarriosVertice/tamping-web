# tamping.app

Sitio público de Tamping: portada, política de privacidad, condiciones de uso y
soporte.

Son cuatro ficheros estáticos sin dependencias ni compilación. Se sirven con
GitHub Pages y la App Store enlaza a `/privacidad.html` y `/soporte.html`, que
son obligatorias para publicar.

Para apuntar el dominio propio: añadir un `CNAME` con `tamping.app` y crear en
el DNS los registros que indique GitHub Pages.
